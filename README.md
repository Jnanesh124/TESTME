## Commands

### 🏠 Basic Commands
```
• /start - Start the bot and show welcome message
• /help - Show help menu with all available commands
• /id - Get Telegram user/chat/channel ID
• /info - Get detailed user information and stats
```

### 📁 File Management & Indexing
```
• /index - Index files from your channel to database
• /setskip - Skip number of messages when indexing files
• /delete - Delete a specific file from index
• /deleteall - Delete all indexed files from database
• /deletefiles - Delete PreDVD and CamRip files from database
```

### 🔍 Filter Commands
```
• /filter - Add manual filters (keyword based responses)
• /filters - View all manual filters in current chat
• /del - Delete a specific filter
• /delall - Delete all manual filters from chat
• /gfilter - Add global filters (work in all chats)
• /gfilters - View list of all global filters
• /delg - Delete a specific global filter
• /delallg - Delete all global filters from database
```

### 🔗 Connection & Settings
```
• /connect - Connect to PM for managing group settings
• /disconnect - Disconnect from PM
• /connections - See all connected groups
• /settings - Open settings menu for bot configuration
• /set_template - Set custom IMDB template for groups
```

### 📊 Statistics & Management
```
• /stats - Get status of files and users in database
• /logs - Get recent bot errors and logs
• /users - Get list of bot users with IDs
• /chats - Get list of bot chats with IDs
• /channel - Get list of connected channels
```

### 👑 Admin Commands
```
• /ban - Ban a user from using the bot
• /unban - Unban a previously banned user
• /leave - Make bot leave from a chat
• /disable - Disable bot in a chat
• /enable - Re-enable bot in a disabled chat
• /restart - Restart the bot server
```

### 📢 Broadcast Commands
```
• /broadcast - Broadcast message to all bot users
• /grp_broadcast - Broadcast message to all connected groups
```

### 🔗 Link Generation
```
• /batch - Create link for multiple posts
• /link - Create link for single post
• /stream - Generate stream and download links for files
```

### 💎 Premium Features
```
• /add_premium - Add user to premium list
• /remove_premium - Remove user from premium list
• /plan - Check premium plan details
• /myplan - Check your premium plan status
```

### 🔗 Shortlink Management
```
• /shortlink - Set URL shortener in your group
• /setshortlinkoff - Turn off shortlink in group
• /setshortlinkon - Turn on shortlink in group
• /shortlink_info - Check group shortlink and tutorial details
• /set_tutorial - Set tutorial link for shortener
• /remove_tutorial - Remove tutorial link
```

### 📺 Force Subscribe
```
• /fsub - Add force subscribe channel in group
• /nofsub - Remove force subscribe from group
```

### 🎬 File Tools
```
• /rename - Rename your files with custom names
• /set_caption - Add caption for renamed files
• /see_caption - View your saved caption
• /del_caption - Delete your saved caption
• /set_thumb - Add thumbnail for renamed files
• /view_thumb - View your saved thumbnail
• /del_thumb - Delete your saved thumbnail
```

### 🎵 Entertainment & Utility
```
• /song - Download songs from various platforms
• /lyrics - Get song lyrics
• /font - Convert text to different font styles
• /tts - Text to speech converter
• /telegraph - Get telegraph link of files under 5MB
• /stickerid - Get sticker ID and unique ID
• /json - Get JSON data of replied messages
• /repo - Search and get GitHub repository links
• /paste - Paste text to pastebin services
• /share - Share text with formatting options
```

### 🎮 Fun Commands
```
• /runs - Send random run strings
• /password - Generate secure passwords
```

### 🤖 Bot Management
```
• /clone - Create your own clone auto filter bot
• /purgerequests - Delete all join requests from database
• /totalrequests - Get total number of join requests
```

### 🔍 Search & Discovery
```
• /search - Search files from various sources
• /imdb - Fetch movie/series info from IMDB
• /engine - Search engine queries
```

### ✅ Verification System
```
• /verify - Start verification process for file access
• /addbadword - Add words to bad word filter (Admin)
• /removebadword - Remove words from bad word filter (Admin)
• /listbadwords - List all bad words in filter (Admin)
• /verifiedusers - Show all verified users (Admin)
```

### 🎯 Auto Features
- **Auto Filter**: Automatically responds to movie/series queries
- **Auto Approve**: Automatically approve join requests
- **Auto Delete**: Delete files after specified time
- **Spell Check**: AI-powered spell checking for queries
